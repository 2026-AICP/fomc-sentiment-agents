## 0. 무엇을 검증했나

조교님 표현을 그대로 쓴다.

> **Fed communication tone 이 이후 Fed policy action 과 얼마나 정렬되어 있는지,
> 그리고 기존 정보에 추가적인 정보가 있는지를 검증한다.**

"Fed 자신의 행동이라 인과 해석 논쟁에서 자유롭다"는 표현은 쓰지 않는다 — 과한 주장이다.

이 분석의 부수 효과가 하나 더 있다. 지금까지 프로젝트의 모든 근거(News:Fed 1:1,
Fed 내부 1:1:1)가 **VIX 상관** 위에 서 있었는데, VIX 는 지도교수 피드백으로 보류
상태다. 금리결정은 연준 자신의 행동이므로, **보류된 지표에 의존하지 않는 근거**가 된다.

### 결론 요약

| 대상 | 결과 |
|---|---|
| **금리결정** (primary) | 정렬은 확인된다. 다만 **예측력은 지속성 기준선을 넘지 못한다** |
| **2년물 반응** (secondary) | 발표된 결정·시장 기대를 통제하고도 **톤이 유의하다**. 견고성도 통과 |

## 1. 설계에서 먼저 막은 것 두 가지

### 1-1. 동시점 누출

성명문은 회의 당일 발표되고 본문에 결정이 **그대로 서술**된다
(`"the Committee decided to raise the target range ..."`). 이 톤으로 결정을 맞히면
설명이 아니라 동어반복이다.

그래서 primary 의 예측자는 **회의 t 가 열리기 전에 알 수 있는 것만** 쓴다.

| 예측자 | 시점 |
|---|---|
| 직전 회의(t-1) 성명문·기자회견 톤 | t-1 당일 공개 |
| 직전 회의(t-1) 회의록 톤 | t-1 의 3주 후 공개 → t 전에 도착 |
| 뉴스 지수 | t 직전에 **완결된** 달 |
| 2년물 사전 변화 | t 직전 20거래일 |

회의 간격이 21일 미만이라 직전 회의록이 아직 공개 전이었을 **7건은 결측 처리**했다.

누출을 뺀 대가는 없었다 — 직전 회의 톤의 그룹 간 격차(0.321)가 오히려 동시점(0.254)보다 크다.

### 1-2. 기준선 착각

최빈 클래스(Hold 66.5%)를 기준으로 삼으면 성공을 과장한다. 연준 결정은 사이클로
움직여 **직전 결정을 그대로 반복하기만 해도 80.5%** 다.

| 기준선 | 정확도 |
|---|---|
| 최빈 클래스 (Hold) | 66.5% |
| **직전 결정 반복 (지속성)** | **80.5%** ← 이길 대상 |

목표변수는 FRED 목표금리 변화로 객관 측정한다(사람 라벨 불필요) —
`DFEDTAR`(~2008) + `DFEDTARU`(2008~), |변화| ≤ 0.05 면 동결.
`tone_vs_policy.py` 가 쓰던 정의와 같다.

**분포**: Hike 40건(18.1%) · Hold 147건(66.5%) · Cut 34건(15.4%), 총 221회의.

## 2. 조건부 빈도표

모형 이전에 맨눈으로 보는 단계. 각 예측자를 3분위로 나눠 결정 비율을 본다.

| 예측자 | 인하 비율 (1→2→3분위) | Cramér's V |
|---|---|---|
| 회의 전 20거래일 2년물 | 31.1% → 6.8% → 8.2% | 0.314 |
| **직전 회의록 톤** | **31.4% → 5.7% → 1.4%** | **0.313** |
| 직전 성명문 톤 | 32.4% → 11.0% → 2.7% | 0.256 |
| 직전월 뉴스 지수 | 31.7% → 8.3% → 6.7% | 0.256 |
| 직전 기자회견 톤 | 패턴 없음 (p=0.579) | 0.125 |

**세 축(성명문·회의록·뉴스) 모두 금리결정과 단조로 연동된다.** 회의록이 성명문보다
강한 것이 눈에 띈다 — 회의록은 참가자들의 향후 견해를 담아 정보량이 많다.

지속성 구조 자체도 표로 남긴다. 인하→인상, 인상→인하 전이는 **0.0%** 다 — 연준은
방향을 곧바로 뒤집지 않는다.

## 3. 금리결정 (primary) — 다항 로지스틱

3분류이므로 OLS 가 아니라 다항 로지스틱을 쓴다(조교 피드백). 중첩 모형을 **사전에
고정**해 각 층의 증분만 본다 — 변수 조합을 뒤져 좋은 걸 고르지 않는다.

```
M0  지속성      직전 결정만
M1  + 시장기대  회의 전 20거래일 2년물 변화
M2  + Fed 톤    직전 회의 성명문·회의록
M3  + 뉴스      직전 완결월 뉴스 지수
```

뉴스 축이 2021-05 에서 끝나므로 트랙을 둘로 나눈다. M3 기준으로 표본을 맞추면
**2022~23 인상 사이클이 통째로 빠지기** 때문이다.

### 표본 내

| 트랙 | 모형 | pseudo-R² | 앞 모형 대비 |
|---|---|---|---|
| Fed 축 (210건, ~2026) | M0 | 0.371 | — |
| | M1 | 0.417 | p=0.000 |
| | M2 | 0.443 | **p=0.060** |
| 뉴스 포함 (169건, ~2021) | M0 | 0.359 | — |
| | M1 | 0.418 | p=0.000 |
| | M2 | 0.472 | p=0.005 |
| | M3 | 0.499 | p=0.026 |

pseudo-R² 절대값으로 의미를 주장하지 않는다(조교 피드백). 모형 간 차이로 읽는다.

### 표본 외 — 확장 윈도우

시계열이므로 **무작위 분할은 하지 않는다**. 각 회의를 그 이전 회의들로만 학습해
예측하고, 표준화도 매 시점 과거 구간으로만 한다.

| 트랙 | 모형 | 정확도 | 로그손실 | macro-F1 |
|---|---|---|---|---|
| Fed 축 (130건 예측) | 기준선 지속성 | **77.7%** | — | **0.646** |
| | M1 +시장기대 | 74.6% | 0.600 | 0.573 |
| | M2 +Fed톤 | 73.8% | 0.626 | 0.531 |
| 뉴스 포함 (89건 예측) | 기준선 지속성 | 76.4% | — | 0.478 |
| | M2 +Fed톤 | 76.4% | 0.602 | 0.399 |
| | M3 +뉴스 | **78.7%** | **0.589** | **0.515** |

**전 구간에서는 모형이 지속성 기준선보다 나쁘다.** 뉴스를 포함한 2021까지 구간에서만
M3 가 소폭 앞선다(78.7% vs 76.4%).

### 그래서 어떻게 서술하는가

> **정렬(alignment)은 확인되나, 예측력은 지속성 기준선을 넘지 못한다.**

조교님이 "In-sample 만 할 경우 '과거 조건부 경향'이라는 표현이 정확하다"고 하신
그 상태다. primary 에 대해서는 예측을 주장하지 않는다.

## 4. 2년물 반응 (secondary) — 여기가 더 강하다

조교 피드백: *"2년물 국채금리도 좋은 secondary outcome. 다만 '다음 회의까지의 변화'보다
짧은 window 부터 보는 게 더 좋다."*

종속변수가 연속이므로 여기서는 **OLS 가 맞다**(조교님의 OLS 지적은 3범주 primary 한정).
표준오차는 HAC(Newey-West, 4시차).

여기서는 **동시점 톤을 쓰는 것이 맞다** — primary 에서는 성명문이 결정을 서술해
누출이었지만, 2년물 반응에서는 톤이 원인 쪽이고 금리 반응이 결과 쪽이다. 다만
결정 자체가 금리를 움직이므로 **결정 더미로 반드시 통제**한다.

```
B0  결정 더미      인상·인하 (동결 기준)
B1  + 사전 기대    회의 전 20거래일 2년물 변화
B2  + 성명문 톤    톤이 그 위에 추가 정보를 주는가
```

| 반응 창 | 톤 계수 | HAC p | ΔR² |
|---|---|---|---|
| 1거래일 | +0.0430 | 0.043 | +0.020 |
| **2거래일** | **+0.0602** | **0.008** | +0.026 |
| 3거래일 | +0.0342 | 0.154 | +0.007 |
| 5거래일 | +0.0096 | 0.725 | +0.000 |

**짧은 창에서만 유의하고 5일이면 사라진다.** 조교님의 "짧은 window 부터"가 데이터로
확인됐다. 정보가 빠르게 흡수된다는 뜻이라 해석도 자연스럽다.

### 설계 변형 격자 — 전부 공개

여러 설계 중 가장 좋은 하나만 보고하면 p값이 부풀려진다(다중비교). 그래서 **16개
조합을 전부 싣는다.**

| 톤 구성 | 창 2일 계수 | p | n |
|---|---|---|---|
| **성명문** | **+0.0602** | **0.008** | **221** |
| 성명문+기자회견 | +0.1259 | 0.056 | 93 |
| 성명문+뉴스 | +0.0477 | 0.022 | 180 |
| 뉴스 단독 | +0.0445 | 0.438 | 180 |

전체 격자는 `outputs/policy_rate2y.csv` 참조.

**채택: 성명문 단독 × 창 2일.** 성능이 가장 좋기도 하지만, 선택 근거를 성능 외로도 댈 수 있다.

1. **전 표본을 쓴다**(n=221, 2000~2026). 기자회견은 2011년 이후만 존재해 93건,
   뉴스는 2021년에 끝난다
2. **이론적으로 가장 깨끗하다** — 성명문이 발표 시점에 나오는 바로 그 커뮤니케이션이다
3. **창 2일이 네 개 톤 구성 중 셋에서 최선**이다. 한 칸이 운으로 걸린 게 아니라 구조다

기자회견을 넣으면 계수가 두 배(+0.126)가 되지만 n=93 이라 p=0.056 이다. 효과가
없는 게 아니라 표본이 부족한 것이므로 **별도 주장이 아니라 보조 관찰**로 남긴다.

뉴스 단독은 당일 2년물 반응을 설명하지 못한다(p=0.438) — 뉴스는 발표 이전 기간의
정보이므로 당연한 결과다.

### 회의록을 후보에서 뺀 이유

회의록은 회의 3주 뒤 공개된다. 회의 당일~2일 금리 반응을 회의록으로 설명하면
**미래 정보를 쓰는 것**이다. 성능이 좋게 나오더라도 쓸 수 없으므로 애초에 후보에서 제외했다.

## 5. 견고성 5종 (조교 피드백 질문 4-4 지정 목록)

| 검사 | primary (M1→M2 우도비) | secondary (톤 계수, 창 2일) |
|---|---|---|
| 전체 (기준) | LR=9.0 p=0.060 | +0.0602 **p=0.008** |
| ① 2008·2020 제외 | LR=11.8 **p=0.019** | +0.0506 p=0.021 |
| ② 2011년 이후 (기자회견 도입 후) | LR=3.1 p=0.543 | +0.0794 p=0.081 |
| ③-a 2000~2008 (회의록 수작업) | 수렴 실패 | +0.1038 **p=0.005** |
| ③-b 2009년 이후 (자동수집) | LR=1.0 p=0.915 | +0.0516 p=0.155 |
| ④ 톤 수준 → 톤 변화(ΔTone) | LR=8.0 p=0.091 | +0.0411 p=0.176 |
| ⑤ 확장 윈도우 OOS | 기준선 못 넘음 (§3) | 미검증 |

**primary 는 취약하다.** 위기를 빼면 오히려 강해지는 것(p=0.019)은 좋은 신호다 —
위기 한두 개가 만든 결과가 아니라는 뜻이다. 그러나 2009년 이후에는 사라진다.
ZIRP 시기라 동결만 반복돼 변동 자체가 거의 없는 것이 큰 이유로 보인다.

**secondary 는 견고하다.** 계수의 부호와 크기가 모든 부분표본에서
**+0.04 ~ +0.10** 으로 유지된다. p값이 커지는 것은 표본이 줄어든 검정력 문제이지
효과가 사라진 것이 아니다 — 판단은 계수의 안정성으로 한다.

**④ 답**: 절대 톤이 변화보다 중요하다(secondary p=0.008 vs 0.176).

③-a 에서 MNLogit 이 준-분리로 수렴에 실패했다. `nan` 을 결과로 흘리지 않고
'수렴 실패'로 명시한다 — 자료의 성질이지 버그가 아니다.
