## 0. 한 줄 컨셉

> **"+0.554 와 -0.094 를 반으로 나눴더니, +0.23 이 아니라 -1.099 가 나왔습니다.
> 그날 밤, 숫자 하나가 사라졌습니다."**

프로젝트를 "설명"하지 않는다. **사건을 수사하는 과정에서 시스템이 저절로 드러나게** 한다.
피해자를 쫓다 보면 관측소 구조가 보이고, 범인을 쫓다 보면 방법론이 보인다.

## 1. 왜 이 사건인가 — 사건 후보 3안

| | 사건 | 훅 | 드러나는 것 | 평가 |
|---|---|---|---|---|
| **A** ⭐ | **사라진 0.23** (`docs/headline_norm_issue.md`) | 양수 + 양수 = 음수 | 두 축 결합 구조 · z 표준화 · 온도 · 자기수정 | **추천.** 시작 5초에 훅이 터지고, 범인·동기·해결·미제까지 완비 |
| B | **50%의 미스터리** (`docs/phase5_comparison.md`) | 적중률 50%, 동전던지기인가 | 시장은 톤이 아니라 *서프라이즈*에 반응 | 반전은 좋으나 3분엔 설명 부담이 큼 |
| C | **기사 6건으로 울린 경보** (`docs/ta_feedback_2026-08.md`) | 근거 6개로 경고를 보낸 시스템 | CI 게이트 · 정직성 설계 | 휴먼 드라마는 약하나 윤리 메시지가 강함 |

→ **A안 채택.** B·C는 시리즈 2·3화 소재로 남겨둔다.

### 사건의 실제 팩트 (각색 아님)

- **2026-09-05**, 공개 대시보드 홈에 통합 감성지수 **-1.099** 표시
- 화면 설명: *"Fed +0.554 · 뉴스 -0.094 를 1:1 로 결합"* → 산술적으로 **+0.23** 이어야 함
- 지수 전체 범위가 **-7.08 ~ +4.35**. z-척도에서 |z|>3 은 1000일에 몇 번 수준인데, 5일이나 있었음
- **진범: 온도 3.1.** 2026-07 당시 쓰던 온도보정(T=3.1) 기준 z-파라미터가
  `analysis/headline_norm.json` 에 남아 있었다. 2026-08 에 지도교수 피드백으로 **T=1 로 복귀**
  하며 지수는 전부 재생성됐지만, **이 파일 하나만 갱신되지 않았다.**
- **공범 둘**: 월별 파라미터를 일별에 적용 · 모집단이 WSJ 백본인데 Marketaux 에 적용
- **해결: 커밋 `8dc5879`** — 범위 -4.55~+3.46, 9/5 값 **-0.323**
- **미제로 남은 것**: C안(주별 백필 재추정) 적용 시 -2.17~+1.52, |z|>3 인 날 0일.
  단 일별 변동성 16% 과소평가는 한계로 명시 — **아직 결정 대기 중**

> 이 사건이 좋은 이유: 부호와 순서는 내내 맞았다. 틀린 건 **자(尺)** 였다.
> "관측 기계가 자기 자를 의심하는 이야기" — 연구 프로젝트의 본질 그 자체다.

## 4. 제작 가이드

### 4-1. 배우 없이 만드는 법 (전부 화면 소스로 대체)

| 그알의 장치 | 우리의 대체물 |
|---|---|
| 사건 현장 CCTV | **대시보드 화면 녹화** (실제 사이트) |
| 통화 기록·출입 기록 | **`git log --oneline`** 스크롤 · 커밋 해시 |
| 용의자 관계도 | **`agents/graph.py` 파이프라인 도식** |
| 압수한 증거 문서 | **`docs/*.md`** 문서를 스캔 질감으로 |
| 국과수 감정 결과 | **터미널 재계산 실행 장면** |
| 제보자 모자이크 인터뷰 | (선택) 팀원 뒷모습 + 음성변조 1컷 — 있으면 완성도 급상승 |

### 4-2. 그알 룩 만들기 체크리스트

- **색보정**: 채도 낮춤, 하이라이트 살짝 날림, 전체적으로 청록빛 그림자
- **붉은 강조**: 핵심 숫자마다 손으로 그린 듯한 붉은 원 / 화살표 (After Effects 또는 Canva)
- **자막 폰트**: 굵은 고딕 흰색 + 검정 외곽선. 나레이션 핵심 구절만 화면 하단에
- **흔들림**: 결정적 순간마다 0.3초 핸드헬드 셰이크 + 셔터 스틸컷
- **정적**: 「그런데 말입니다」 **앞에 반드시 1초 무음**. 이 침묵이 이 포맷의 전부다
- **음악**: 오프닝 = 불안한 현악 트레몰로 / 3막 진범 = 저음 드럼 단타 / 클로징 = 피아노 단음
  (저작권 프리: YouTube Audio Library "Documentary / Suspense" 카테고리)

### 4-3. 나레이션 톤

김상중 톤의 핵심은 **성대모사가 아니라 호흡**이다.
- 문장을 **짧게** 끊는다. 한 호흡에 한 문장.
- 서술은 평탄하게, **질문만 살짝 올린다**.
- 감정을 싣지 않는다. 건조할수록 무섭다.
- 「-였습니다」 종결을 반복해 리듬을 만든다.
- 발화 속도 분당 약 280–320자. 3분 대본 전체 나레이션 = **약 900자** (현재 대본 기준 적정).

### 4-4. 유의사항

- 오프닝·클로징 타이틀은 **오마주임이 드러나되 원본 로고·음원은 그대로 쓰지 않는다.**
  제목을 「그 **지수**가 알고싶다」로 비튼 이유.
- 엔딩 자막에 패러디 고지를 반드시 넣는다 (위 대본에 포함).
- 금융 정보인 만큼, 영상에 **"예측이 아닌 경향"** 면책 한 줄을 넣으면 프로젝트 원칙과도 일치한다.
