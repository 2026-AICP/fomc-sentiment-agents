## 1. 이 영상은 무슨 사건을 다루는가

### 한 줄 컨셉

> **"그날, 정보는 전부 공개돼 있었습니다.**
> **그런데 그는 끝내 아무것도 알지 못했습니다."**

### 사건 개요

| 항목 | 내용 |
|---|---|
| **발생** | 2026년 9월 17일. FOMC 금리 결정 발표 |
| **피해자** | **정보 비대칭에 시달리는 대학생** — 탭 수십 개를 열고도 결론에 닿지 못한 사람 |
| **피해** | 시간·판단력·기회. 그리고 "나만 모르는 것 같다"는 감각 |
| **1차 의심** | 누군가 정보를 감추고 있다 |
| **알리바이** | 성명문 공개 · 기자회견 생중계 · 의사록 전문 공개 · 기사 무료. **감춘 자가 없다** |
| **질문 전환** | *아무도 감추지 않았는데 아무도 알 수 없다면 — 범인은 '숨김'이 아니라 '양'인가* |
| **진범 ①** | **양** — 성명문 + 기자회견 + 의사록 + 하루 약 150건의 기사 |
| **진범 ②** | **결** — 같은 회의인데 문서마다 말이 다르다. **회의의 73%에서 기자회견이 성명문보다 신중했다** |
| **해결** | 그 많은 '말'을 AI가 전수로 읽어 **지수 하나 · 등급 하나**로. 지수↑ → 시장 공포(VIX)↓ (26년치 검증) |
| **결말** | 이제 찾아갈 필요가 없다. **9/17 그날 아침, 시스템이 스스로 읽고 먼저 메일을 보냈다** (기사 139건) |

### 왜 이 사건인가

**① 피해자가 시청자 자신이다.**
사라진 숫자가 피해자면 구경꾼이 되지만, 대학생이 피해자면 시청자가 당사자가 된다. 인기투표가 걸린 영상에서 이 차이는 결정적이다.

**② "범인이 없는데 피해자만 있다"는 구조가 성립한다.**
추적 다큐에서 가장 서늘한 회차는 언제나 이 구조다. 그리고 이건 연출이 아니라 정보 비대칭의 실제 성질이다 — 누구도 악의를 갖지 않았는데 피해는 발생한다.

**③ 73%가 반전으로 기능한다.**
v2에서는 시스템 소개 중 한 줄이었지만, 사건 구조에 넣으면 의미가 달라진다. *정보는 감춰져 있지 않았다. 다만 어느 문을 여느냐에 따라 다른 얼굴을 보여주고 있었다.* 팀이 직접 발견한 사실이 곧 사건의 진상이 된다.

**④ v2의 수미상관이 그대로 클라이맥스가 된다.**
탭 수십 개 → 메일 한 통. 여기에 "제보자의 정체 공개"를 겹치면 마지막 18초에 감정과 메시지가 동시에 닫힌다.

> **핵심 메시지** — 정보의 비대칭은 누군가 **감추어서** 생기는 것이 아니라, 아무도 **정리해 주지 않아서** 생긴다.

## 2. 출연 — 4인 배역표

| 배역 | 담당 | 화면 등장 | 처리 | 분량 |
|---|---|---|---|---|
| **① 진행자** | 팀원 A | 1:12 현장 / 2:42 클로징 | 처음부터 공개 | 나레이션 전편 + 얼굴 **30초** |
| **② 피해자·제보자** | 팀원 B | 0:00 연기 / 0:30 인터뷰 / **2:42 정체 공개** | **역광·뒷모습 → 후반 공개** | **연기 35초 + 대사 20초** |
| **③ 설계** | 팀원 C | 1:24 / 2:24 | `EconPilot · 시스템 설계` | **22초** |
| **④ 검증** | 팀원 D | 1:52 / 2:30 | `EconPilot · 지표 검증` | **20초** |

### 배역 설계 의도

**① 진행자 — 얼굴을 아낄수록 무거워진다**
나레이션은 전편을 맡되 얼굴은 두 번만. 수사가 막혀 질문을 뒤집는 순간(1:12)과 마지막 성찰(2:42). 세 번째 등장을 넣는 순간 이 두 번이 가벼워진다.

**② 피해자 겸 제보자 — v2 주인공을 그대로 승계**
v2의 "개미 대학생"이 곧 이 사건의 피해자다. 다만 추적 다큐 문법에 맞춰 **초중반은 얼굴을 보여주지 않는다** — 뒷모습·손·모니터 반사·역광 실루엣.
이건 연출이자 동시에 **공모 규정(개인식별정보 금지)에 대한 안전장치**이기도 하다.
그리고 2:42, 메일 한 통을 여는 장면에서 **처음으로 얼굴이 보인다.**
→ 탭 수십 개에 파묻혀 얼굴조차 없던 사람이, 신호 한 줄을 받고서야 얼굴을 되찾는다.

**③ 설계 — 진범을 지목하는 사람**
"사람이 다 못 읽으면 전부 읽게 하면 된다"는 발상의 전환과, 73% 발견을 증언한다.

**④ 검증 — "진짜 맞냐"에 답하는 사람**
지수↑ → 공포↓. 26년치. 그리고 신호 등급.
