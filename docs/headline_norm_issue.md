# 통합 감성지수 z-파라미터 불일치 — 현황 보고

> 2026-09-06 · 발견 경위: 대시보드 9/5 통합지수 -1.099 가 표시된 두 축 값
> (Fed +0.554 · 뉴스 -0.094)으로 설명되지 않는다는 지적
> 대상 파일: `analysis/headline_norm.json`

## 요약

대시보드 홈의 **통합 감성지수 절대 크기를 현재 신뢰할 수 없습니다.**
부호와 날짜 간 상대 순서는 맞습니다.

z-표준화 파라미터가 **온도보정(T=3.1)을 쓰던 2026-07 시점 값**인데,
2026-08 에 T=1 로 되돌리면서 지수는 전부 재생성됐으나 이 파일은 갱신되지
않았습니다. 여기에 월별 파라미터를 일별에 적용하는 문제가 겹쳐,
지수가 z-척도로서 비정상적인 범위(**-7.08 ~ +4.35**)를 보였습니다.

### 진행 상황 (2026-09-06)

원인 세 가지 중 **온도 불일치는 처리했고, 나머지 둘은 문의 중**입니다.

| | 항목 | 상태 |
|---|---|---|
| (1) | 온도 — T=3.1 시절 파라미터 | **처리 완료** (`8dc5879`) |
| (2) | 집계 단위 — 월별 → 일별 | 문의 중 (C안) |
| (3) | 모집단 — WSJ 백본 → Marketaux | 문의 중 (C안) |
| — | 표기가 척도와 어긋나던 문제 | **처리 완료** (`8dc5879`) |

**처리한 것**은 "원래 하려던 것의 복구"라 방법론 변경이 아닙니다.
`build_headline_norm.py` 를 다시 돌려 파라미터를 T=1 기준으로 맞췄고,
화면 표기를 결합에 실제로 들어간 z 값으로 바꿔 `index = 0.5·fed + 0.5·news_z`
가 검산되게 했습니다. 그 결과 지수 범위가 **-7.08~+4.35 → -4.55~+3.46**,
`|z|>3` 인 날이 5일 → 3일이 됐습니다. (9/5 값 -1.099 → **-0.323**)

**문의 중인 것**은 C안(백필 주별 재추정)입니다. 파라미터의 **출처**를
바꾸는 것이라 방법론 변경에 해당해 판단을 여쭙니다(6절).
적용하면 범위가 **-2.17~+1.52**, `|z|>3` 인 날이 0일이 됩니다.
남는 오차(일별 변동성 16% 과소평가)는 한계로 명시합니다(7절).

## 1. 발견된 증상

2026-09-05 대시보드 표시:

```
통합 감성지수  -1.099
"Fed +0.554 · 뉴스 -0.094 를 1:1 로 결합"
```

두 값을 1:1로 평균내면 +0.23 이 나와야 하는데 -1.099 가 표시됩니다.

### 실제 계산식

산술 오류는 아닙니다. 실제로는 이렇게 계산됩니다.

```
통합 = 0.5 × Fed(이미 z-점수)  +  0.5 × z(뉴스 원값)

z(뉴스) = (-0.0941 - 0.0842) / 0.0648 = -2.75
통합    = 0.5 × 0.5545 + 0.5 × (-2.75) = -1.099   ✓
```

**Fed 는 이미 z-점수**입니다(성명문·회의록·기자회견을 각각 표준화해 평균).
**뉴스는 원값**(-1~+1)이라 결합 시점에 표준화됩니다.
표시 문구는 척도가 다른 두 숫자를 나란히 보여주고 있습니다.

## 2. 근본 원인 — 파라미터가 세 겹으로 어긋남

`analysis/headline_norm.json` 의 news 파라미터는 `mean 0.0842 · std 0.0648` 입니다.

### (1) 온도(T) 불일치 — 가장 큰 문제

| 날짜 | 커밋 | 내용 |
|---|---|---|
| 2026-07-07 | `023961b` | z-파라미터 생성 (news mean 0.0842 / std 0.0648) |
| **2026-08-03** | `8240208` | **raw FinBERT(T=1) 전환** — 지도교수 피드백으로 온도보정 제거 |
| 2026-08-24 | `1066adf` | Fed 축 3성분 추가 — `news`·`fed` 키는 손대지 않음 |

파라미터는 T=3.1 시절 값입니다. T=1 전환 때 지수는 재생성됐지만
이 파일은 재생성되지 않았습니다.

같은 스크립트(`analysis/build_headline_norm.py`)를 지금 다시 돌리면 다른 값이 나옵니다.

| | mean | std |
|---|---|---|
| `headline_norm.json` (저장값) | 0.0842 | 0.0648 |
| 현재 `outputs/news_index.csv` 로 재계산 | **0.0167** | **0.0924** |

평균이 5배 차이 납니다.

> **왜 아무도 몰랐나**: `outputs/` 가 gitignore 라 `news_index.csv` 는 커밋되지
> 않습니다. 파라미터와 원본이 어긋나도 diff 에 잡히지 않았습니다.

### (2) 집계 단위 불일치 — 월별 파라미터를 일별에 적용

`build_headline_norm.py` 는 **월별** 시계열에서 mean/std 를 구합니다.

```python
NEWS_CSV = ROOT / "outputs" / "news_index.csv"   # WSJ 백본 월별 지수
def _z(s):
    return (s - s.mean()) / s.std()
```

그 값을 **일별** 뉴스 지수에 적용합니다. 월별 평균은 하루하루의 등락이
상쇄돼 잔잔하므로, 그 좁은 표준편차로 일별 값을 나누면 z 가 부풀려집니다.

| | std |
|---|---|
| 파라미터 (월별·WSJ) | 0.0648 |
| 실제 일별 분포 (라이브 65일) | **0.2398** |

일별 변동성이 **3.7배**입니다.

> 기준: `daily_headline.json` 의 뉴스 일별 원값 65일(2026-07-03~09-05) —
> 통합지수 계산에 실제로 들어가는 그 값입니다(ddof=1).

### (3) 모집단 불일치

파라미터는 **WSJ 백본**(2000~2021)에서 나왔고, 적용 대상은 **Marketaux 라이브**입니다.
두 계열은 선정 규칙이 달라 월별 지수 상관이 r=0.43 에 그칩니다
(`docs/scope_impact.md`).

### Fed 축도 같은 상태입니다

| | mean | std |
|---|---|---|
| `headline_norm.json` | 0.1490 | 0.1649 |
| 현재 DB 로 재계산 (318개월) | 0.1555 | **0.2532** |

평균은 비슷하나 표준편차가 1.5배 어긋나 있습니다.

## 3. 영향 — 얼마나 왜곡되나

9/5 의 뉴스 -0.0941 이 몇 σ 로 평가되는지:

| 기준 | 값 |
|---|---|
| 현행 파라미터 | **-2.75 σ** (극단적 이상치) |
| 실제 일별 분포 | **-0.55 σ** (평범하게 낮은 날) |

지수 전체 분포도 z-척도로서 비정상입니다(라이브 65일).

| | 날 수 |
|---|---|
| \|지수\| > 2 | 11일 (17%) |
| \|지수\| > 3 | 5일 (8%) |
| \|지수\| > 4 | 4일 (6%) |
| \|지수\| > 5 | 2일 (3%) |

정규분포라면 \|z\|>3 은 0.3% 여야 합니다. 실제로는 8% 입니다.

### 진폭 예시

| 날짜 | 뉴스 원값 | 통합지수 |
|---|---|---|
| 09-03 | +0.210 | +1.248 |
| 09-04 | +0.274 | +1.742 |
| 09-05 | -0.094 | **-1.099** |

뉴스가 0.37 움직이는 동안 통합지수가 2.84 움직입니다.

코드 주석(`analysis/export_dashboard.py`)에 적혀 있었습니다.

> 크기가 약 4배 부풀려진다 — 부호와 상대 순서는 맞지만 절대 크기는 아직

같은 원값(Fed·뉴스)으로 통합지수만 다시 계산했습니다. 라이브 65일 기준입니다.

|---|---|---|---|---|---|
| 이전 (T=3.1·월별·WSJ) | 0.0842 / 0.0648 | -1.099 | -7.08 ~ +4.35 | 1.841 | — |
| **A** T=1 재생성 (월별·WSJ) — **현재 적용** | 0.0167 / 0.0924 | **-0.323** | **-4.55 ~ +3.46** | 1.293 | 7일 |

## 6. 문의 — C안 (백필 주별 재추정)

### 채택 이유

백필(2021-01~2026-07, 285주)은 **라이브와 선정 규칙이 같습니다**
(Marketaux 본문 F → 제목+설명 F∧M). 따라서 2절의 세 가지 원인 중
**(1) 온도와 (3) 모집단이 동시에 해소**됩니다.

| 후보 | 모집단 | 집계 단위 | 표본 | 라이브 일별 std 대비 |
|---|---|---|---|---|
| 이전 | WSJ ✗ | 월별 ✗ | — | 0.27배 |
| **A (현재 적용)** | WSJ ✗ | 월별 ✗ | 257개월 | 0.39배 |
| **C (문의)** | **백필 ✓** | 주별 ✗ | **285주** | **0.84배** |
| B | 라이브 ✓ | 일별 ✓ | 65일 | 1.00배 (표본 부족) |

B안이 척도는 가장 정확하지만 표본이 65일뿐이라 추정이 불안정하고
시간이 지나며 값이 계속 변합니다. C안은 표본이 충분하고 값이 고정됩니다.

### 적용 후 달라지는 것

현재 적용 중인 A 에서 C 로 바꾸면 이렇게 됩니다.

```
news:  mean 0.0167 → 0.0781      std 0.0924 → 0.2005
```

| | A (현재) | C 적용 시 |
|---|---|---|
| 지수 범위 (라이브 65일) | -4.55 ~ +3.46 | **-2.17 ~ +1.52** |
| \|지수\| > 3 인 날 | 3일 (5%) | **0일 (0%)** |
| 9/5 값 | -0.323 | -0.152 |
| 라이브 일별 std 대비 | 0.39배 | **0.84배** |

z-척도로서 정상 범위에 들어옵니다. A 만으로는 아직 2.6배가량 부풀려집니다.

### 이미 처리한 것 (2026-09-06)

- **Fed 축 파라미터**도 어긋나 있었습니다(std 0.1649 대 0.2532, 1.5배).
  `build_fed_axis_norm.py` 로 함께 재생성했습니다.
- **표시 문구 수정.** "Fed +0.554 · 뉴스 -0.094 를 1:1 로 결합" 이
  척도가 다른 두 값을 나란히 보여주고 있었습니다. 결합에 실제로 들어간
  z 값을 보여주도록 바꿔 화면 숫자로 검산됩니다.
- 문서·코드 12곳의 VIX 상관 인용도 T=1 값으로 정정했습니다
  (-0.534 → -0.524 등, `d2b60b0`). 결론은 불변입니다.

### 바뀌지 않는 것

- **결합 방식**(z-표준화 후 News:Fed = 1:1)은 그대로입니다.
  바뀌는 것은 z 파라미터의 출처뿐입니다.
- **FinBERT 모델·파라미터와 무관**합니다. 채점 결과는 건드리지 않습니다.

## 7. 한계 — 일별 변동성 16% 과소평가

C안은 **주별** 분포에서 파라미터를 구해 **일별** 값에 적용하므로
2절 (2)의 집계 단위 불일치가 완전히 해소되지는 않습니다.

| | std |
|---|---|
| C안 파라미터 (백필 주별) | 0.2005 |
| 라이브 일별 실측 | 0.2398 |

**16% 과소평가**입니다. 결과적으로 **z 값이 약 1.2배(20%) 과대**하게 나옵니다.
평균도 백필 주별이 +0.0781, 라이브 일별이 +0.0388 로 달라
라이브 값이 평균적으로 **+0.20σ 낮게** 평가됩니다.

이전(0.27배)과 현재 A(0.39배)에 비하면 훨씬 작은 오차이고 방향 해석에는
영향이 적지만, **절대 크기를 정밀하게 인용할 때는 이 점을 함께 밝혀야 합니다.**

### 왜 남는가 — 표본 두께 때문

주별 구간은 기사가 중앙값 62건 모여 잡음이 상쇄되고,
라이브 일별은 중앙값 14건이라 잡음이 더 큽니다.

백필을 일별로 집계해 분산을 분해하면 이렇게 나옵니다(1,829일).

```
Var(지수) = 0.0658 + 0.4368 / n
            ↑참신호      ↑기사 표집 잡음
```

| 하루 기사 수 | 예상 지수 std |
|---|---|
| 7건 (백필 현실) | 0.358 |
| 14건 (라이브 현재) | 0.311 |
| 25건 (판정 범위 확대 후) | 0.289 |

즉 백필을 그대로 일별 집계하면 오히려 **1.69배 과대**가 됩니다
(하루 7건이라 잡음이 큼). 주별이 0.84배로 더 가깝습니다.

### 더 정확히 하려면

파라미터를 고정 상수가 아니라 **기사 수의 함수**로 두면
(위 분산분해식 사용) 오차를 거의 없앨 수 있습니다.
다만 "척도가 날마다 달라진다"는 것을 별도로 설명해야 하고,
원래 설계(고정 mean/std)에서 한 걸음 더 나가는 변경입니다.

라이브 수집이 충분히 쌓이면(1년 이상) B안(라이브 일별 직접 추정)으로
옮기는 것이 가장 단순합니다. **그때까지는 C안 + 이 한계 명시**로 둡니다.

```bash
# C안 파라미터 (백필 주별) 산출 — 기사별 채점 캐시에서 재집계
python -c "
import pandas as pd, math
a = pd.read_csv('outputs/news_backfill_scored.csv', parse_dates=['dt'])
a['w'] = (1 - a.entropy/math.log(3)).clip(lower=0); a['sw'] = a.score*a.w
g = a.groupby(a.dt.dt.to_period('W'))
W = g.sw.sum()/g.w.sum().clip(lower=1e-9)
print(len(W), W.mean(), W.std(ddof=1))"
```
