### ⚠️ 부분 완료

**질문 5 — 표본이 적은 날의 신호 발동 (신뢰도 게이트)**

*문제*: 일별 지수는 부트스트랩 95% CI를 계산해 표시하면서, 정작 신호 등급은 CI를
무시하고 점추정치만으로 발동했다. **기사 6건(CI가 0을 크게 걸침)인 날에도 "주의"가
나갔다.**

*조교 답변*: A안(게이팅)·B안(표시)의 절충 — **측정은 그대로 두고 경보만 게이팅.**

*반영*: `agents/graph.py::strategy_node` 에 `news_signals.confident()` 배선.
기사 15건 미만이거나 CI 폭 0.60 초과면 `주의`/`경고` 를 **`⚪ 관망`** 으로 낮춘다.
지수 값 자체는 건드리지 않는다 — 기사 1~2건인 날 지수가 크게 튀지만(실측 +7.09),
값을 빼면 시계열에 구멍이 생긴다. 발동 목록도 기록용으로 남긴다.
→ `1066adf`, `13bb420`, 머지 `fad59b3`

*2026-08-27 재점검 — 두 가지가 남아 있다.*

**(가) 조교님이 지목한 증상의 절반만 막고 있다.** 원문은 *"기사 6건(**CI가 0을 크게
걸침**)"* 이다. 게이트는 기사 수와 **CI 폭**을 보지만 **0 을 걸치는지는 보지 않는다.**
`divergence`(🔴 경고)와 `sign_flip` 은 지수의 **부호**로 판정하는데, 구간이 0 을
걸치면 그 부호를 말할 수 없다. 표본 유일의 🔴 경고가 여기 해당한다.

```
2026-07-17  🔴 경고   지수 +0.058   95% CI  -0.170 ~ +0.287
            → "뉴스는 긍정인데 시장은 하락(-1.01%)" 이 논리인데,
              뉴스가 긍정이었는지 자체를 말할 수 없다.
              CI 폭 0.457 은 상한 0.60 을 여유 있게 통과한다.
```

56일 중 **44일(79%)** 이 부호 불명이고, 부호 확정 + 기사 15건 이상은 **5일**뿐이다.
**`ci_max` 를 조인다고 잡히지 않는다 — 검사 항목이 하나 빠져 있다.**

**(나) 게이트 임계값 자체에 근거가 없다.** 15·0.60 은 파일 생성 커밋(`2450d75`,
2026-07-03)에서 데이터 없이 찍은 값이다(그날은 뉴스 지수 첫날). 민감도 분석 결과
`min_articles` 는 8~30 으로 흔들어도 등급 변동이 최대 5일/56일(9%)이라 방어 가능하지만,
`ci_max` 는 0.30 에서 56일 전부가 관망이 되고 유일한 🔴 을 뒤집는다.
→ `docs/gate_sensitivity.md`, `04f570e`

*처리 방침은 미정이다.* 부호 검사를 넣으면 현재 표본에서 경보가 5일로 줄어든다 —
헛경보를 줄이는 대가로 사례가 거의 사라진다. 결정 사항으로 남긴다.

  7번(이틀에 한 번)이라 기각했다.
- **정정 알림 = 확정판으로 등급이 실제로 바뀐 경우만.** 질문 6 의 속보치/확정판
  설계와 직접 연결된다.
- **구독자 정보는 리포에 커밋하지 않는다.** 공개 MIT 저장소이고 이력이 영구히 남는다.

*적중 기준 사전 등록*: 알림이 맞았는지 채점하려면 기준이 **알림보다 먼저** 있어야
한다. 2000-01-03~2026-08-25 전 거래일 6,701일로 계산해 고정했다.
→ `analysis/hit_thresholds.py`, `docs/alert_hit_thresholds.md`, `2358765`

```
알림 후 5거래일 안에
  |S&P 누적수익률| > 3.74%   또는   |ΔVIX| > 4.76pt   → 적중
  무작위 날짜의 적중률(귀무가설) = 14.5%
```

여기서 **설계 문서의 오류를 하나 잡았다.** 초판은 *"상위 10% 기준이면 무작위 적중률은
정의상 10%"* 라고 적었는데, 조건이 "S&P **또는** VIX" 인 합집합이라 실제로는 **14.5%**
다(10.0 + 10.0 − 5.5). 그대로 뒀으면 **적중률을 10% 와 비교해 성과를 1.45배 부풀렸을
것이다.** 같은 오류가 검정력 계산에도 옮겨가 있어, **유의성 판정에 필요한 기간이
1년(n=20, p≈0.15)이 아니라 2.5년(n=60, p≈0.02)** 으로 늘었다. → 문서 §9 정정 기록

TA 질문 4-3(무작위 분할 금지)·4-4(위기 견고성)의 원칙도 같이 적용했다 — 평가 대상은
`computed_at` 이후 발송된 알림뿐이고, 2008·2020 을 빼도 임계값이 4% 남짓만 움직인다.

*남은 것*: **구현은 시작하지 않았다.** 도메인 확보 → Resend 도메인 검증 → Worker/KV →
구독 UI → Notifier 노드 순이고, 각 단계는 별도 승인 후 진행한다.

## 3. 여쭐 내용

**질문 1 — VIX 표시 여부**

Fed 축 내부 가중치를 1:1:1 로 정한 근거가 **VIX 상관 하나에 서 있다**
(전 구간 -0.418 → -0.577, 홀드아웃 3분할 전부 통과 — `docs/fed_weights.md` §2,
그림 `docs/figures/comparison/fed_weights.png`).

다중 타깃(S&P·Δ10y)에서도 1:1:1 이 1위라 VIX 하나에 맞춘 것은 아니지만, **근거의 축
자체가 보류하신 시장지표**다. 사이트에 VIX 를 어디까지 노출할지, 그리고 이 근거를
그대로 써도 되는지 확인이 필요하다.

**질문 2 — 키워드 조정**

감사 결과(§1-⑦)를 근거로 세 가지를 여쭙는다.

1. **의장 이름을 F그룹에도 인정** — 의장 이름은 연준을 특정하는 표현이다. 규칙을
   바꾸는 게 아니라 *"F = 연준을 가리키는 표현"* 이라는 원래 취지에 맞추는 것.
2. **M그룹에 `FOMC`·`minutes`·`rate hike`·`rate cut` 추가 검토** — 통화정책 자체를
   가리키는 표현인데 빠져 있다. FOMC 회의록 보도 전량 탈락의 직접 원인.
3. **`inflation` 추가는 신중** — 물가 기사 전반이 들어와 정밀도가 크게 떨어질 수 있다.

**질문 3 — 설명력 분석 설계** — §4 의 방향으로 진행해도 되는지.

## 5. 반영하며 지킨 원칙

문서를 나중에 읽을 사람을 위해, 판단이 갈렸던 지점만 남긴다.

**측정과 경보를 분리한다.** 신뢰도가 낮다고 지수를 지우지 않는다. 지우면 시계열에
구멍이 생기고, 나중에 "그날 값이 왜 없지"를 설명할 수 없다. 값은 남기고 등급만 낮춘다.

**과거에 보여준 값은 사후에 바꾸지 않는다.** 자료가 시차를 두고 도착하므로(회의록 3주
뒤), 나중 정보로 과거 기록을 고치면 설명력·예측력이 실제보다 좋아 보인다.

**임계값은 데이터로 정하되, 데이터가 오염됐으면 기다린다.** 신호 임계값(θ)은 분포
분위수로 보정했다(`docs/signal_calibration.md`). 신뢰도 게이트의 15건·0.60 은 아직
**잠정값**이다 — 지금 보정하면 수집이 깨져 있던 기간이 표본에 섞여 버그를 임계값에
박아 넣게 된다. 정상 수집이 3~4주 쌓인 뒤 같은 절차로 보정한다.

**가중치는 튜닝하지 않는다.** 사전에 고정한 후보만 비교한다. 소수점 최적화는 표본에
과적합돼 표본 외에서 오히려 나빠진다(1/N 규칙).

**지도교수 지정 사항은 임의로 바꾸지 않는다.** 키워드에 문제를 발견해도 근거를 만들어
보고하고 결정을 받는다. 수집량이 부족했을 때도 필터를 넓히는 대신, **같은 필터로 더
깊이 표본추출**하는 쪽으로 풀었다(모집단은 그대로, 표본만 확대).
